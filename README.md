# tiny.BIO Site Address Purchase Prototype

Interactive frontend prototype for reviewing the tiny.BIO site address search, cart, checkout, and purchase-success flow.

## Local development

```bash
npm ci
npm run dev
```

## Production builds

- `npm run build` builds the existing Sites-compatible package.
- `npm run build:pages` builds the static GitHub Pages site in `dist/client`.

Pushes to `main` deploy automatically through the GitHub Pages workflow.
